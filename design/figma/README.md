## Exportação pendente

**Os arquivos .fig e PNG ainda não foram exportados nem adicionados ao repositório.** O acesso automatizado ao Figma atingiu o limite de chamadas do plano Starter. Os links acima apontam para os documentos de origem, não para arquivos exportados.

Para exportar manualmente:
1. Abrir cada projeto no Figma.
2. File > Save local copy para obter o .fig (quando disponível).
3. Selecionar frames e usar Export > PNG para gerar imagens.
4. Adicionar os arquivos a `passageiro/` ou `motorista/` nesta branch, após conferir os nomes e evitar informações sensíveis.
