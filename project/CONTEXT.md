# Nexo — Context Snapshot

> Read this file first when entering the project from a new chat.

## Product
Nexo is a multi-service marketplace connecting customers who need a service with providers who can perform it.

## Current phase
Foundation and architecture.

## Current repository state
The repository was intentionally initialized with the continuity system and product documentation before application implementation.

## Business model
R$99.90/month provider subscription. No percentage commission on rides or completed services. Provider keeps 100% of service value.

## Passenger pricing
Car: R$2.00/km.
Motorcycle: R$1.50/km.

These are product-defined base rules and must be economically and legally validated before commercial launch.

## Negotiation
Passenger transport uses the defined tariff model. Cargo transport permits direct negotiation between customer and provider.

## Payments
Physical cash, Pix, and credit/debit card through the provider's own card machine.

## Profiles
Both sides have profiles. Profiles can contain photos, videos and captions, plus ratings/comments subject to moderation.

## Trust
Identity verification, vehicle verification, bilateral ratings, complaints, blocking and fraud prevention are core concepts.

## Scope exclusions
Nexo Live, live streaming, hands-free, speech-to-text/text-to-speech for driving, live camera infrastructure and related consent workflows are out of current scope.

## Current task
Turn the product roadmap into the master technical specification, then define the initial architecture and data model before implementation.

2. Choose/record technology stack.
3. Define architecture.
4. Define database entities and relationships.
5. Define API boundaries.
6. Create implementation foundation.
